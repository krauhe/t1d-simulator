Articles are stored locally in this directory. Each entry is annotated with its local file type:

- **[PDF]** — Full-text PDF (downloaded or open-access)
- **[abstract-note]** — Hand-crafted HTML with extracted abstract, key findings and quantitative data (not a full article)
- **[PMC-HTML]** — Full or partial text saved from PubMed Central
