Protein → glucagon → hepatic glucose production (Paterson 2016)

Protein-driven hepatic glucose production pathway, calibrated to Paterson et al. (Diabet Med 33:1151-1157, 2016). Ingested protein is absorbed through a two-stage gastric-intestinal cascade (P_stomach → P_gut, shared τG with carbohydrates) into a circulating amino-acid pool (AA). A Hill-saturation function converts AA concentration to a glucagon drive signal (f_hill = PROTEIN_GLUCAGON_MAX · AAⁿ / (EC50ⁿ + AAⁿ); n = 2, EC50 = 8 g, max = 0.25). Liver glycogen reserve R scales f_hill by (0.5 + 0.5·R): when glycogen is replete the full glucagon effect (glycogenolysis + gluconeogenesis) applies; when glycogen is depleted only the gluconeogenesis half (~50 %) persists. The resulting signal is added to the unified stressMultiplier, which competes with insulin x3 suppression in the EGP equation. Calibration target: 75 g protein → +1.6–1.7 mmol/L peak BG at 150–180 min.
