# Diagrams

This folder contains SVG illustrations of physiological and implemented models
used by the T1D simulator. Each figure has its own subfolder with a JSON spec
(the source of truth), the rendered SVG, a Markdown caption, and an automated
validation screenshot.

Figures are generated by the `diagrammaker` skill, which uses the renderer in
`tools/diagrammaker/`. See `tools/diagrammaker/schema.md` for the DSL.

## Folder layout

```
docs/diagrams/
  README.md                      <- this file
  <slug>/                        <- one folder per figure
    spec.json                    <- DSL definition (the source)
    figure.svg                   <- rendered output
    caption.md                   <- short caption for embedding
    validation.png               <- visual snapshot from Chrome
    validation.json              <- geometric overlap-check results
```

To embed a figure in a Markdown file (typically in `docs/MODEL-IMPLEMENTATION.md`
or `docs/BG-SCIENCE.md`):

```markdown
![Insulin pharmacokinetics](diagrams/insulin-pk/figure.svg)

*Two-compartment subcutaneous absorption feeds plasma insulin, which drives
three effect compartments...*
```

The caption text from `caption.md` can be used verbatim or summarised inline.

## Visual language

### Compartments (boxes)
- Rounded rectangles, radius 10px (matches the simulator's `--radius-md`)
- Fill: entity color at 20% alpha
- Border: entity color at full opacity, 2px
- Border style:
  - **Solid** = mass-storage compartment (depot, plasma, tissue)
  - **Dashed** = effect compartment (signal-driven, no mass)
  - **Dotted** = external source/sink (outside the modelled system)
- Label inside box: name (e.g. `Plasma insulin`), variable (e.g. `I`),
  optional unit (e.g. `mU/L`)

### Arrows (flows)
- **Solid arrow** = mass flow (physical transport, e.g. SC absorption)
- **Dashed arrow** = signal/effect (e.g. insulin action on glucose disposal)
- **Double-headed arrow** = bidirectional equilibrium
- Arrow color matches the source compartment's entity color
- Arrow label is the rate constant or rate equation, on a white background

### Direction
- Default: left-to-right (input from left, output to right)
- Top-to-bottom available via `"direction": "top-to-bottom"` in spec
- The renderer enforces no arrow-arrow crossings and no text overlap

## How to add a new figure

1. Create `docs/diagrams/<slug>/spec.json` describing compartments and flows
2. Run: `tests/.bin/node.exe tools/diagrammaker/render.js docs/diagrams/<slug>/spec.json`
3. Run: `tests/.bin/node.exe tools/diagrammaker/validate.js docs/diagrams/<slug>/figure.svg`
4. Take a visual snapshot via headless Chrome (see SKILL.md for the command)
5. Write `caption.md` (one short paragraph in italics, define all variables)
6. Add a row to the index above
