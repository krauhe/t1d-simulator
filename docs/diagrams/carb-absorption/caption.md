*Carbohydrate absorption uses the Hovorka two-compartment gut model (D1, D2). The simulator extends the original fixed τG = 40 min with a dynamic, mixture-dependent τG: the stomach is treated as a continuously stirred-tank reactor whose four mixture variables (total carbs, simple-sugar mass, fiber, retention-weighted weight) are updated additively when food enters and decay proportionally as the stomach empties. Each tick τG = carbBase · fiberMod · retentionMod + fatDelay is recomputed and feeds back into the D1 → D2 emptying rate. **D1**: stomach compartment in the Hovorka gut model (mmol carb); **D2**: gut compartment (mmol carb); **U_G**: glucose appearance into plasma; bioavailability A_G ≈ 0.8; **τG**: dynamic gastric emptying time (~25 min liquid sugar, ~80 min whole-grain, +0–45 min from fat); **carbBase** = 25 + (1 − simpleFrac) × 25 — chemical complexity term (25–50 min); **fiberMod** = 1 + 0.5 · ln(1 + fiber/2) — saturating fiber slowdown; **retentionMod** = 1 − 0.6 · (1 − retentionRatio) — liquids empty faster (0.4–1.0); **fatDelay** = 18 · ln(1 + fatIntestine/10) — Wolpert/Smart pizza effect; **simpleFrac**: stomachCarbsSimple / stomachCarbsTotal; **retentionRatio**: stomachRetentionWeight / stomachContentGrams. Empty-stomach fallback: τG = 40 min when stomachContentGrams < 0.1.*
