Insulin pharmacokinetics — core Hovorka 2004 model

Core insulin pharmacokinetics subsystem from the Hovorka 2004 glucose-insulin model (Hovorka et al., Physiol Meas 25:905-920, 2004). A two-stage subcutaneous absorption cascade (S1 → S2) transfers insulin to plasma compartment I at rate U_I = S2/τ_I; plasma insulin is eliminated at rate ke · I and simultaneously drives three effect compartments x1 (glucose transport Q1 → Q2), x2 (peripheral disposal), and x3 (EGP suppression). This diagram covers the core Hovorka structure only — no basal shadow cascade, no EGP node, no glucose pools. See insulin-action-egp for the extended simulator view including basal cascade and EGP regulation.
