*The simulator's ketone model is FFA-driven and gated by plasma insulin at two levels. (1) Lipolysis: insulin suppresses hormone-sensitive lipase via a Hill function (EC50 ≈ 8 mU/L, n = 3) — the lowest insulin EC50 of any process, so even basal insulin keeps lipolysis off. (2) CPT-1: insulin → ACC → malonyl-CoA → blocks CPT-1 (EC50 ≈ 8 mU/L, n = 4) — nearly binary. Ketone production is the product ffaLipolysis × cpt1Activity; both gates must be open. BHB is cleared by Michaelis-Menten oxidation in muscle and brain (boosted by exercise) and by renal excretion above 0.5 mmol/L. DKA game-over uses an acidosis load that accumulates above BHB 3.0 mmol/L with a smooth insulin gate so that fasting ketosis (insulin present) does not trigger. **I**: plasma insulin (mU/L) — the master regulator of ketogenesis; **lipolyseRate** = LIPOLYSIS_MAX · EC50ⁿ / (EC50ⁿ + Iⁿ) — Hill suppression by insulin; **ffaLipolysis**: endogenous FFA pool from adipose lipolysis (separate from dietary ffaBlood); **FFA_LIPO_CLEAR_HALF** = 60 min (oxidation + re-esterification); **cpt1Activity** = 1 − CPT1_MAX_SUPP · Iⁿ / (EC50ⁿ + Iⁿ); 1.0 fully open at I=0, ~0.05 at high I; **bhbProduced** = BHB_PROD_RATE · ffaLipolysis · cpt1Activity · dt; BHB clearance Vmax = 0.02, Km = 2.0; exercise boost = 1 + max(0, ΔHR / 120); renal: BHB_RENAL_VMAX = 0.005 / min, threshold 0.5 mmol/L, Km = 2.0; acidosis rate = (BASE · excess + ACCEL · excess²) · insulinSuppression; smoothstep insulin gate: 0 when suppression ≤ 0.3, 1 when ≥ 0.5 (avoids fasting-ketosis false alarm); game over: acidosisLoad ≥ 600; recovery t½ = 45 min when BHB drops below threshold.*
