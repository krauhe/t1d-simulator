Ketone & DKA model — FFA-driven, two-gate ketogenesis (Cahill / Kitabchi)

FFA-driven ketogenesis and DKA acidosis model implemented in the T1D simulator, structured after the ketone physiology described in Cahill Jr GF, N Engl J Med 282:668-675 (1970) for the two-gate ketogenesis pathway, and DKA severity criteria from Kitabchi et al., Diabetes Care 32:1335-1343 (2009). Plasma insulin I suppresses ketone production at two sequential gates: (1) the lipolysis gate — insulin inhibits hormone-sensitive lipase (HSL) via a Hill function (EC50 = 8 mU/L, n = 3), reducing FFA release from adipose; (2) the CPT-1 gate — insulin raises malonyl-CoA via acetyl-CoA carboxylase (ACC), blocking carnitine palmitoyltransferase-1 and preventing mitochondrial FFA import (EC50 = 8 mU/L, n = 4). Both gates must be open for ketone production: BHB production rate = LIPOLYSIS_MAX * lipolysisGate * ffaLipolysis * cpt1Activity * k_BHB. BHB is removed by Michaelis-Menten oxidation in muscle and brain (exercise-boosted) and by renal excretion above 0.5 mmol/L. Acidosis load accumulates above BHB 3.0 mmol/L with a smoothstep insulin gate that prevents nutritional ketosis from triggering DKA; game over fires when acidosisLoad reaches 600.
