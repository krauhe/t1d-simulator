12Smart repeat (dobbelt-tap)

Enkelt tap: åbn portion-popup. Dobbelt-tap: spis direkte med standard portion. Triple-tap: dobbelt portion. Skjult power-feature for øvede spillere.

Touch gestures:
• Enkelt tap → åbn stepper
• Dobbelt tap → spis 1× straks
• Hold nede 500ms → åbn stepper (samme som enkelt-tap, men med haptic feedback)

Ingen af disse er hover-afhængige. Alle virker på mobil.

13Data-driven arkitektur (js/foods.js)

Alle mad-data flyttes til én fil. Gør det nemt at ændre, tilføje eller A/B-teste madvalg. 

// js/foods.js
const FOODS = {
  pizza: {
    id: 'pizza',
    row: 'normal',        // 'lowcarb' | 'normal' | 'adjust'
    i18nKey: 'food.pizza',
    emoji: '🍕',
    carbs: 55,
    protein: 20,
    fat: 25,
    weight: 220,         // gram per standard portion
    liquid: false,
    key: 'F',           // keyboard shortcut (desktop)
    unlockLevel: 1,     // campaign gating
  },
  druesukker: {
    id: 'druesukker',
    row: 'adjust',
    i18nKey: 'food.druesukker',
    icon: 'svg/druesukker.svg',  // SVG replaces emoji
    carbs: 3,
    fastCarb: true,      // flag for hurtig absorption (τ = 15 min)
    key: 'Z',
    unlockLevel: 1,
  },
  // ... alle andre fødevarer
};
