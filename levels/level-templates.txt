LEVEL-SKABELONER - CAMPAIGN MODE
Genereret: 2026-04-18

STATUS: Historisk planmateriale - ikke kilde til aktuel spillertekst.
De aktive kilder er js/levels.js, js/i18n.js og js/guide-data.js.
Ny tekst skal følge docs/INTENDED-PURPOSE.md og handle om faste, fiktive karakterer.

Formål:   skitsér de første 8 kampagne-baner. Bane 1-3 findes allerede i
          js/levels.js (skabelonen viser deres nuværende indhold som reference).
          Bane 4-8 er nye ideer der skal fyldes ud over tid - foreslåede temaer
          er sat i toppen af hver bane som udgangspunkt, men kan ændres.

Workflow: fyld felter ud her efterhånden som ideer kommer. Når en bane
          er klar, oversættes den til js/levels.js i det rigtige format.

Format-regler (samme som TODO.txt og tips-templates.txt):
  - UTF-8 med BOM
  - dansk tegnsætning (æ, ø, å) - ALDRIG ae/oe/aa
  - ASCII-alternativer: '-' for tankestreg, 'x' for gange
  - ingen emoji, em-dash, eller unicode-specialtegn


===============================================================================
SEKTIONER PER BANE
===============================================================================

Hver bane har 4 sektioner, plus de tekniske attributter:

1. LÆRINGSMÅL  (INTERN INFO - ikke i kode)
   1-3 korte punkter: "Hvad skal spilleren forstå efter banen?"
   Bruges som rettesnor for level-design, intro-tekst og tips.
   Kommer ALDRIG i UI - kun design-dokumentation.

2. INTRO-POPUP  (vises ved bane-start, pauser spillet)
   Tekniske felter i koden:
     titleKey         : i18n-nøgle (campaign.levelN.title)
     descriptionKey   : i18n-nøgle (campaign.levelN.desc) - kort introduktion
     intro.whatHappensKey  : i18n-nøgle (campaign.levelN.whatHappens)
                             prosa: "Hvad sker der i banen?"
     intro.preStartTipsKey : i18n-nøgle (campaign.levelN.preStartTips)
                             prosa: "Tips inden du starter"
   I template'en udfyldes:
     Beskrivelse       : (= descriptionKey indhold)
     Hvad sker der?    : (= whatHappensKey indhold)
     Tips inden start  : (= preStartTipsKey indhold)

3. ATTRIBUTTER  (alle tekniske felter fra js/levels.js)
   Se ATTRIBUT-REFERENCE nedenfor.

4. TIPS  (samlet liste - vises under spil)
   Per tip:
     id              : unik streng
     oneShot         : true  = vises KUN første gang (sætter permanent flag)
                       false = vises gentaget med cooldown
     triggerType     : levelStart | afterAction | bgAbove | bgBelow | time |
                       panelOpen | iobAbove | actionCount | eventTriggered
     triggerValue    : tærskel (fx 4.0 for bgBelow, 480 for time-minutter)
     cooldownMinutes : kun for oneShot=false (default 60)
     condition       : noRecentBolus | noBasalGiven | noFoodGiven | iobStacking
     timeWindow      : { startHour, endHour } - filter ovenpå trigger
     afterAction     : food | fastInsulin | basalInsulin | exercise (for trigger)
     highlightElement: CSS-selector (typisk for oneShot=true)
     textKey         : i18n-nøgle


===============================================================================
ATTRIBUT-REFERENCE (alle felter fra js/levels.js)
===============================================================================

  id                  : unik streng, fx 'dag4_icr' (bruges til localStorage)
  number              : bane-nummer, vises i UI
  titleKey            : i18n-nøgle (campaign.levelN.title)
  descriptionKey      : i18n-nøgle (campaign.levelN.desc)

  startTimeMinutes    : sim-starttid i minutter (0-1440), fx 420 = kl. 07:00
  durationMinutes     : varighed (1440 = 1 døgn, 4320 = 3 døgn)
  startBG             : start-blodsukker i mmol/L

  intro:
    whatHappensKey    : i18n-nøgle (campaign.levelN.whatHappens)
    preStartTipsKey   : i18n-nøgle (campaign.levelN.preStartTips)

  physics:
    disableWeightTracking : true = ingen game over ved kalorieunderskud
    disableDawnEffect     : true = ingen cirkadisk kortisol (flad morgen)
    disableKetones        : true = ingen keton-produktion (slukker DKA)
    basalPreInjected      : true = basal allerede givet ved start

  enabledActions:
    food          : true/false  - mad-panel tilgængeligt
    fastInsulin   : true/false  - bolus-panel tilgængeligt
    basalInsulin  : true/false  - basal-panel tilgængeligt
    exercise      : true/false  - motion-panel tilgængeligt
    kit           : true/false  - nødhjælps-kit (sukker, glukagon)

  scheduledEvents     : array af automatiske hændelser
    type: 'autoFood'
    timeMinutes: sim-tidspunkt
    + makro-felter (carbs, protein, fat, weight, carbType, icon)

  markers             : visuelle markører på grafen
    type: 'action'    - noget spilleren skal gøre
    type: 'info'      - observation/info
    type: 'interval'  - interval med start- og slut-tid
    timeMinutes ELLER startMinutes/endMinutes
    icon, labelKey, syringeColor (blue=basal, teal=bolus)

  objectives          : mål der skal opfyldes
    type: 'actionRequired' - spilleren skal udføre EN handling
    type: 'actionCount'    - spilleren skal udføre N handlinger
    type: 'survive'        - spilleren skal overleve hele banen
    actionType: 'food', 'fastInsulin', 'basalInsulin', 'exercise'

  stars               : stjerne-rating baseret på TIR% (Time In Range, 4-10 mmol/L)
    one:   { minTIR: X }
    two:   { minTIR: Y }
    three: { minTIR: Z }

  tips                : SAMLET liste af bane-tips (gammel tutorialTips + tips)
    Hvert tip har oneShot: true/false som styrer om det er engangs eller
    gentages med cooldown. Se "SEKTIONER PER BANE" ovenfor for fulde felter.

LÆRINGSMÅL (intern info): lær at give basal insulin og bruge menuerne i bunden, mht. basal insulin og evt. jursterings mad. Brug af hastigheds kontrol.
  -
  -

INTRO-POPUP:
  Beskrivelse        : Basal insulin:

			Du starter ved midnat. Du tog sidst en hel dosis basal insulin igår kl 8, denne dosis holder          		  dig stabil igennem formiddagen.
                       Hvis BG falder for lavt, kan du op jurstere med med fra mad-panelet eller T1D-kittet. For at gøre det let i starten, skal du ikke tænke på mad generelt, men kun bruge snaks til evt. at jurster dit BG op.
                       Brug "<" ">" knapperne (tastatur: pil-venstre/-højre)
                       til at ændre simulations hastighed.

  Hvad sker der?     : Uden insulin begynder leveren at frigive glucose og ketoner.  Dette hæver BG og keton 			niveauet. Keton niveauet kan måles med en keto-stik.  


  Tips inden start   : På insulin menuen står din anbefalede basal dosis (baseret på ... ? isf / vægt? )
Forsøg dig med at tage mere eller mindre basal insulin. Forsøg dig med at tage det om morgenen, om aftenen, eller ½ dosis på hver tidspunkt. Hvordan kan du få flest points. 



ATTRIBUTTER:
  id                  : dag1_basal
  number              : 1
  startTime           : 00:00 
  varighed            : 3 døgn (4320 min)
  startBG             : 6.0 mmol/L

  physics             : disableDawnEffect=true, disableWeightTracking=true
                        ketoner ER aktive (viser hvorfor basal er vigtigt)

  enabledActions      : basalInsulin, food (juster linje kun), kit
                        IKKE: fastInsulin, exercise

  scheduledEvents     : ingen

  markers             : interval kl. 07:00-14:00 "Giv basal insulin"

  objectives          : actionRequired - giv basal insulin

  stars               : 1*=70% (anbefalses ofte som et mål, lad os kvitere med en stjerne for det) TIR, 2*=85%, 3*=95%

TIPS:
  - id: tut_dag1_dock           [oneShot: true]
    triggerType: levelStart
    tekst: "Tryk på sprøjte-ikonet i bunden for at åbne insulin-panelet"
    highlightElement: insulin dock-item

  - id: tut_dag1_speed          [oneShot: true]
    triggerType: afterAction (basalInsulin)
    tekst: "Du har givet basal! Brug < > knapperne til at ændre hastighed"
    highlightElement: #speedStepper

  - id: tip_dag1_no_basal       [oneShot: false, cooldown 60 min]
    triggerType: time (kl. 08:00)
    condition: noBasalGiven
    tekst: "Du har ikke givet basal insulin endnu - uden basal stiger BG
            langsomt hele dagen"

  - id: tip_dag1_bg_rising      [oneShot: false, cooldown 60 min]
    triggerType: bgAbove (14.0)
    condition: noBasalGiven
    tekst: "BG stiger! Basal insulin holder blodsukkeret stabilt i baggrunden"

Egne noter          :
  -tip_dag1_bg_rising - istedet for at kikke på blodsukker, burde der kikkes på basal niveau basal IOB eller plasma basal. BG stigning kan være pgf. for meget juice.

tut_dag1_speed : har skrvetet at man starter midnat, så her kan vi allerede prøve at speede op indtil kl 7, når der igen sker noget..

GENERELLE NOTER
===============================================================================

  Banens progression skal følges som "RTS-tutorial":
  - Bane 1: kun basal
  - Bane 2: + dawn
  - Bane 3: + bolus + mad
  - Bane 4: + ICR-justering
  - Bane 5: + korrektur (ISF)
  - Bane 6: + motion
  - Bane 7: + pizza/fedt
  - Bane 8: + alle elementer i en hel dag

  Vigtigt: hver bane skal kunne klares på < 5 min realtid (med speed-up).
  Stjerne-systemet driver replay - krævende for 3 stjerner men opnåelig.

  Spilleren skal aldrig føle sig "fanget" - mulighed for at give op og
  gå tilbage til bane-vælger.

  Egne generelle noter      :
